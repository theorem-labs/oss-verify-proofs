## Method (independent)

- **Images**, with sha256 checked against each MANIFEST:
  - fuzz_uci.asan `56822e26...`
  - fuzz_uci.asan-ubsan `8d07ffcf...`
  - fuzz_boxreg.asan `4532568b...`
  - fuzz_boxreg.asan-ubsan `1d548458...`
  - fuzz_identity.asan `5b0cbe57...`
- **Kit:** `sha256sum -c SHA256SUMS` passes for all 7 files; sha256(SHA256SUMS) = `4bbd3a74be8994d0...`. I copied exactly those files to a temporary directory and used `strictcmp2.tcmp` and `strictcmp2.py cmp` from there.
- **My code** (it does not use the builder's code, and the kit only as stated):
  - pyelftools 0.33 for ELF parsing; my own RV64 decoder; capstone 5.0.7 only for listings.
  - Scripts (session scratch, not committed): `the reviewer's scratch directory`, files `img.py trace.py audit.py calls.py fulltcmp.py tables.py extra.py rvdis.py gen.py`.
- **For each row, in U and in R separately:**
  - Decode the word and pair it with its auipc to get the target.
  - Check the target: no FUNC / OBJECT symbol covers it, no symbol sits at it, and it is in .rodata.
  - Read the file bytes through the NUL and compare them with the row.
  - Trace the address along every path: both ways at each branch, jumps inside the function, 8-byte stack spills and reloads, and callee-saved registers across calls. Record every call, return, store, load, derived value and indirect jump.
  - Printf / Report / AppendF calls: resolve the format string and map the register to its conversion.
  - Other callees: trace one level into the callee.
  - Returns: find every call site of the function and trace a0 in the caller.
- **Result of the trace:** for all 141 rows in all three slices, U and R give the same set of events. No string row has a store, a load, a derived pointer or an indirect jump; only the table rows have derived values (the index `add`).
- **Tables:** I read the bound from the disassembly and compared the entries: value tables byte by byte over the range the index can reach; jump tables as function+offset; relative pointer tables as symbol+offset, or as a C string through its NUL when the entry target is unnamed; absolute pointer tables as symbol+offset.
