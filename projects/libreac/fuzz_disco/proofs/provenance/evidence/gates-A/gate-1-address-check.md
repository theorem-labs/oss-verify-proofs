# Gate 1 — address checker of record, image A (fuzz_disco.asan)

Kind: measurement; proves no function. Re-run on the series base against the image A pin; it carries the values of the
lib/A files that no script reproduces.

## Command (run.sh `pac`, every path a variable; no host path)

```
port_addr_check.py --git $HUB --donors-from $DONORS --summary --fail-on-flags \
  --src $CGIF_REF:proofs/cgif/cgif_file_fuzzer/lib --dst $BASE:proofs/libreac/fuzz_disco/lib \
  --paired-only --map A/=A/ --map =Reusable/ \
  --src-image A=$CGIF_BIN.asan --src-image B=$CGIF_BIN.asan-ubsan --src-image P=$CGIF_BIN.plain --src-image U=$CGIF_BIN.ubsan \
  --dst-image A=$PIN_A:$TWIN_A --dst-image B=$PINS/fuzz_disco.asan-ubsan:$TWINS/fuzz_disco.asan-ubsan \
  --dst-image P=$PINS/fuzz_disco.plain:$TWINS/fuzz_disco.plain --dst-image U=$PINS/fuzz_disco.ubsan:$TWINS/fuzz_disco.ubsan \
  --assign '**=auto' --include 'A/**' --cache $OUT/addr/cache --out $OUT/addr/pac-A.tsv
```

Images are keyed by build letter A / B / P / U (never `img=`): a run keyed otherwise leaves the named-symbol rule
unmeasured and is void. The destination images carry their unstripped twins as the symbol source (`ELF:SYMS`); gate
twin-check.txt shows PT_LOAD 2..4 of each twin and its pin are byte-equal, so the twin's symtab describes the pin.

## Per-row triage

`addr/addr_triage.py` gives every one of the 12439 flagged rows one class, `right` / `DEFECT` and a per-row detail,
from measurements it makes here (the pin, its unstripped twin, cgif's symbols and the checked files); the rows no rule
covers are named one by one in `addr/hand-triage.tsv`, each with a `check` the script evaluates. It refuses (exit 1) on
an untriaged row, a failed check, or a hand row that matches nothing. The full per-row table is regenerated by
`addr_triage.py` from a re-run (the 34 MB checker output and the 1.4 MB per-row table stay off the branch, rule 1).
